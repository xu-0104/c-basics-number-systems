# 第 1 課：二進位、十進位、十六進位

## 1. 核心觀念：「位值」

十進位 `253` 其實是：

```
2×10²  +  5×10¹  +  3×10⁰
= 200  +  50     +  3
```

每往左一格，就乘一次「底數」。十進位底數是 10，二進位是 2，十六進位是 16。

| 進位 | 底數 | 用到的符號 | C 語言寫法 |
|---|---|---|---|
| 二進位 (binary) | 2 | 0 1 | `0b1101`（GCC 支援，C23 標準） |
| 十進位 (decimal) | 10 | 0–9 | `13` |
| 十六進位 (hexadecimal) | 16 | 0–9、A=10、B=11、C=12、D=13、E=14、F=15 | `0xD` |

**為什麼電腦用二進位？** 電路只有「有電 / 沒電」兩種狀態 → 1 和 0。一個 0/1 叫 1 **bit**，8 個 bit 叫 1 **byte**。

**為什麼工程師愛用十六進位？** 二進位太長不好讀，而 **1 個十六進位數字剛好 = 4 個 bit**，轉換超快。韌體工程師看暫存器、記憶體位址幾乎都用 hex。

## 2. 二進位 → 十進位：把「有 1 的位置」的權重加起來

先背這排權重（2 的次方）：

```
位置:   7    6    5    4    3    2    1    0
權重: 128   64   32   16    8    4    2    1
```

例：`1011 0110`

```
1×128 + 0×64 + 1×32 + 1×16 + 0×8 + 1×4 + 1×2 + 0×1
= 128 + 32 + 16 + 4 + 2 = 182
```

## 3. 十進位 → 二進位：一直除以 2，餘數「由下往上」讀

例：`13`

```
13 ÷ 2 = 6 餘 1   ↑
 6 ÷ 2 = 3 餘 0   ↑
 3 ÷ 2 = 1 餘 1   ↑
 1 ÷ 2 = 0 餘 1   ↑  ← 從這裡往上讀
答案：1101
```

（另一個快速法：從最大的權重開始「能減就減」。13 = 8 + 4 + 1 → 1101）

## 4. 二進位 ↔ 十六進位：每 4 個 bit 一組

從**右邊**開始每 4 位切一組，不夠就左邊補 0：

```
1011 0110
  B    6    → 0xB6
```

反過來 `0x3F`：`3` = `0011`，`F` = `1111` → `0011 1111`

這張表要熟到不用想：

| hex | bin | hex | bin |
|---|---|---|---|
| 0 | 0000 | 8 | 1000 |
| 1 | 0001 | 9 | 1001 |
| 2 | 0010 | A | 1010 |
| 3 | 0011 | B | 1011 |
| 4 | 0100 | C | 1100 |
| 5 | 0101 | D | 1101 |
| 6 | 0110 | E | 1110 |
| 7 | 0111 | F | 1111 |

## 5. 十六進位 → 十進位

`0x2A` = `2×16 + 10×1` = 42
（或先轉二進位 `0010 1010` 再算，也可以）

## 6. 面試常見的「直覺數字」

- 1 byte = 8 bit，範圍 `0x00`–`0xFF` = 0–255
- `0xFF` = 255、`0x100` = 256、`0xFFFF` = 65535
- 2¹⁰ = 1024（1 KB）
