# 第 5 課：陣列與字串

## 1. 陣列：一排連在一起的盒子

如果要存 5 個分數，寫 5 個變數 `s1, s2, s3, s4, s5` 很笨，而且沒辦法用迴圈處理。
**陣列 = 同一種型別、連續排在一起的一排盒子，共用一個名字，用編號（index）存取。**

```c
int scores[5] = {90, 75, 60, 88, 100};
//              [0] [1] [2] [3] [4]   ← 編號從 0 開始！
```

```
記憶體：
┌────┬────┬────┬────┬─────┐
│ 90 │ 75 │ 60 │ 88 │ 100 │   每格 4 bytes（int），緊緊相鄰
└────┴────┴────┴────┴─────┘
 [0]  [1]  [2]  [3]  [4]
```

```c
printf("%d\n", scores[0]);    // 90（第一個）
printf("%d\n", scores[4]);    // 100（最後一個 = 長度 - 1）
scores[1] = 80;               // 改第二個
```

**為什麼從 0 開始？** index 的意思是「離開頭差幾格」。第一個盒子就在開頭，差 0 格。

### 初始化的規則

```c
int a[5] = {1, 2};       // 沒給的自動補 0 → 1 2 0 0 0（實測）
int b[5] = {0};          // 全部歸 0 的慣用寫法
int c[] = {3, 6, 9};     // 不寫大小，編譯器數給你 → 大小 3
int d[5];                // ⚠️ 區域陣列沒初始化 = 垃圾值（跟第 3 課的 n 一樣）
```

### 用迴圈走過整個陣列（最常見的寫法）

```c
for (int i = 0; i < 5; i++) {      // i 從 0 到 4，注意是 < 5 不是 <= 5
    printf("%d ", scores[i]);
}
```

## 2. 陣列長度：sizeof 的用法和大陷阱

```c
int scores[5];
sizeof(scores)                       // 20：整個陣列 5 × 4 bytes（實測）
sizeof(scores[0])                    // 4：一格的大小
sizeof(scores) / sizeof(scores[0])   // 5：長度 ← 慣用寫法
```

### ⚠️ 陣列傳進函式後，sizeof 就不準了（PTT 作者面試失分的地方！）

```c
void show_size(int arr[])
{
    printf("%zu\n", sizeof(arr));    // 8！不是 20（實測）
}
```

gcc 會警告：`'sizeof' on array function parameter 'arr' will return size of 'int *'`

**原因：** 陣列傳進函式時，C **不會複製整個陣列**，只傳「陣列開頭的地址」（指標）。在 64 位元電腦上，地址是 8 bytes，所以 sizeof 量到的是**地址的大小**。

**正確做法：長度要另外用參數傳進去。**

```c
int sum_array(int arr[], int len)     // 多一個 len 參數
{
    int total = 0;
    for (int i = 0; i < len; i++) {
        total += arr[i];
    }
    return total;
}

sum_array(scores, 5);   // 413（實測）
```

> 而且因為傳的是地址，**函式裡改 `arr[i]`，main 的陣列真的會被改到**——跟第 4 課 swap 的「影本」不一樣！詳細原因 → 下一個聊天室「指標」。

## 3. 超出範圍（out of bounds）：C 不會幫你檢查

```c
int a[5];
a[5] = 99;     // ❌ 最後一格是 a[4]，a[5] 已經在陣列外面了
```

C **不會報錯**，它會照樣寫到 a[4] 後面那塊記憶體——可能蓋掉別的變數、可能讓程式當掉、也可能「看起來沒事」。這是**未定義行為**（第 2 課 scanf 忘記 & 也是）。

最常見的原因是迴圈寫成 `i <= 5`。→ **長度 n 的陣列，合法 index 是 0 ～ n-1。**

## 4. 字串：以 `'\0'` 結尾的字元陣列

C 沒有「字串型別」。字串就是一個 `char` 陣列，**最後多放一個 `'\0'`（數值 0）當結束記號**。

```c
char s[] = "C8";
```

```
┌─────┬─────┬──────┐
│ 'C' │ '8' │ '\0' │   3 個 bytes！
└─────┴─────┴──────┘
 [0]   [1]   [2]
  67    56     0      ← 實測的數值
```

| | 結果（實測） | 意思 |
|---|---|---|
| `sizeof(s)` | 3 | 陣列佔幾個 bytes（包含 `'\0'`） |
| `strlen(s)` | 2 | 字串有幾個字（不含 `'\0'`），要 `#include <string.h>` |

**為什麼需要 `'\0'`？** 陣列傳進函式後只剩地址，函式不知道字串多長。printf 印 `%s` 時就是一個字一個字往後印，**看到 `'\0'` 就停**。

> 第 2 課 scanf 的 `char word[8]; scanf("%7s", word);` 為什麼是 7？因為要留 1 格給 `'\0'`。

### 走過字串的慣用寫法：一直走到 `'\0'`

```c
for (int i = 0; s[i] != '\0'; i++) {
    printf("s[%d] = '%c'\n", i, s[i]);
}
```

不需要知道長度，看到結束記號就停。

### 讀字串

```c
char input[9];              // 最多 8 個字 + 1 個 '\0'
scanf("%8s", input);        // 注意：字串陣列前面「不用」加 &（陣列名稱本身就是地址）
```

### 字元 vs 字串

| 寫法 | 是什麼 | 大小 |
|---|---|---|
| `'A'` | 一個字元（單引號） | 數值 65 |
| `"A"` | 一個字串（雙引號） | 2 bytes：`'A'` 和 `'\0'` |

## 5. 串起來：十六進位字串 → 數值（期末作品的核心！）

使用者輸入 `"C8"`，怎麼算出 200？

先想十進位 `"253"` 怎麼變成 253——**從左到右，每讀一個字，就把目前的值「往左推一位」再加上新的字**：

```
讀 '2'：value = 0   × 10 + 2 = 2
讀 '5'：value = 2   × 10 + 5 = 25
讀 '3'：value = 25  × 10 + 3 = 253
```

十六進位一模一樣，只是乘 16：

```
讀 'C'：value = 0  × 16 + 12 = 12
讀 '8'：value = 12 × 16 + 8  = 200     ← 實測
```

```c
unsigned int value = 0;
for (int i = 0; s[i] != '\0'; i++) {
    int d = hex_digit_value(s[i]);    // 第 4 課的零件 #2！
    value = value * 16 + d;
}
```

（`d == -1` 時代表有非法字元，要處理——這是練習的一部分。）

## 6. 用陣列實現第 1 課的「除以 2，由下往上讀」

第 1 課手算十進位轉二進位：一直除以 2，餘數**由下往上**讀。
問題是：餘數是「由下往上」讀，但程式是「先算出來的先印」——順序反了！
**解法：先把餘數存進陣列，最後倒著印。**

```c
int n = 13, bits[32], count = 0;
while (n > 0) {
    bits[count] = n % 2;      // 存餘數：13→1, 6→0, 3→1, 1→1
    n = n / 2;
    count++;
}
for (int i = count - 1; i >= 0; i--) {   // 倒著印
    printf("%d", bits[i]);
}
// 輸出：1101（實測）
```

```
bits: [1][0][1][1]     ← 存的順序（由上往下）
       ↑           ↑
     倒著印：從 bits[3] 印到 bits[0] → 1101
```

**為什麼大小是 32？** int 最多 32 bit，最多也就 32 個餘數，不會超出範圍。

> 跟第 3 課的「能減就減」法比：這個方法不用事先知道要從哪個權重開始，任何大小的數都能轉。
