# 第 3 課：if / for / while —— 讓程式會「判斷」和「重複」

到目前為止，程式都是從上到下一行一行跑。這一課學兩種改變流程的方法：
- **判斷**（if）：條件成立才做
- **重複**（for / while）：同一件事做很多次

## 1. 比較與邏輯運算子

| 運算子 | 意思 | 例 |
|---|---|---|
| `==` | 等於（**兩個等號！**） | `n == 0` |
| `!=` | 不等於 | `n != 0` |
| `<` `>` `<=` `>=` | 大小比較 | `score >= 60` |
| `&&` | 而且（兩個都成立） | `age >= 18 && age < 65` |
| `\|\|` | 或者（有一個成立就好） | `c == 'y' \|\| c == 'Y'` |
| `!` | 不是 | `!(n > 0)` |
| `%` | 取餘數 | `7 % 2` = 1、`10 % 3` = 1 |

C 沒有「真/假」型別（C99 起有 `bool` 但底層也是整數）：**0 = 假，非 0 = 真**。

`%` 超好用：`n % 2 == 0` 判斷偶數；第 1 課「除以 2 取餘數」轉二進位，就是 `n % 2`。

## 2. if / else if / else

```c
if (score >= 90) {
    printf("A\n");
} else if (score >= 60) {      // 上面不成立才會檢查這裡
    printf("pass\n");
} else {                        // 全部都不成立
    printf("fail\n");
}
```

score = 75 → 印出 `pass`（實測）。由上往下檢查，**第一個成立的就執行，後面全部跳過**。

### ⚠️ 經典陷阱：`=` 和 `==` 搞混

```c
int x = 5;
if (x = 0) { ... }    // ❌ 這是「把 0 放進 x」，不是比較！
```

結果：x 被改成 0，而且 `x = 0` 這個運算的值是 0 → 條件永遠不成立。
gcc `-Wall` 會警告：`suggest parentheses around assignment used as truth value`（實測）。
→ 這是面試「找 bug」題的常客。

## 3. for 迴圈：知道要跑幾次時用

```c
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
// 輸出：1 2 3 4 5
```

括號裡三段，用 `;` 隔開：

```
for ( 起點 ; 條件 ; 每圈結束後做什麼 )
      int i = 1   i <= 5    i++（= i = i + 1）
```

執行順序：起點 → 檢查條件 → 成立就跑 `{ }` → `i++` → 檢查條件 → …… → 條件不成立就離開。

**第 2 課的 02_overflow.c，用迴圈只要這樣：**

```c
unsigned char c = 250;
for (int t = 0; t < 8; t++) {
    printf("%d ", c);
    c = c + 1;
}
// 輸出：250 251 252 253 254 255 0 1
```

## 4. while 迴圈：不知道要跑幾次，只知道「什麼時候停」

```c
int k = 10;
while (k > 0) {
    printf("%d ", k);
    k = k / 2;
}
// 輸出：10 5 2 1
```

這就是第 1 課「一直除以 2 直到 0」的程式版！

`do { ... } while (條件);` 是「先做一次再檢查」，至少會跑一次（例如「先讓使用者輸入，輸入錯就再問」）。

> ⚠️ **無窮迴圈**：條件永遠成立就停不下來（例如忘了寫 `k = k / 2`）。在終端機按 `Ctrl+C` 強制停止。

## 5. break 和 continue

```c
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) continue;   // 跳過這一圈剩下的部分，直接下一圈
    if (i > 8) break;           // 直接離開整個迴圈
    printf("%d ", i);
}
// 輸出：1 2 4 5 7 8   （3、6 被跳過；9 時離開）
```

## 6. 巢狀迴圈：印圖形的核心

外層迴圈管「第幾行」，內層迴圈管「這一行印什麼」。

```c
int rows = 4;
for (int i = 1; i <= rows; i++) {        // 第 i 行
    for (int j = 1; j <= i; j++) {       // 第 i 行印 i 個星星
        printf("*");
    }
    printf("\n");                        // 這一行印完，換行
}
```

```
*
**
***
****
```

### 解圖形題的固定步驟（面試必考「印三角形 / 菱形」）

**不要直接寫程式**，先做一張表，找出「第 i 行」和「要印幾個」的關係：

| 第 i 行 | 星星數 |
|---|---|
| 1 | 1 |
| 2 | 2 |
| 3 | 3 |
| i | **i** |

規律找到了 → 內層迴圈跑 `i` 次。下面的練習都用這個方法：**先列表、找公式、再寫迴圈**。

### 觀念題

1. `if (x = 0)` 和 `if (x == 0)` 差在哪？為什麼前者永遠不成立？
2. 什麼時候用 `for`，什麼時候用 `while`？
3. 下面這段會印出什麼？為什麼？
   ```c
   int i;
   for (i = 0; i < 3; i++);
   {
       printf("%d\n", i);
   }
   ```
   （提示：仔細看 `for` 那行的結尾。先猜，再實際跑跑看！）

### 我的答案

1. `x = 0` 是「把 0 放進 x」，不是比較；這個運算的結果就是 0（= 假），所以條件永遠不成立，而且 x 還被改掉了。`x == 0` 才是比較。gcc `-Wall` 會警告 `suggest parentheses around assignment used as truth value`。
2. 知道要跑幾次（例如印 n 行、權重 128 → 1 跑 8 次）用 `for`；只知道「什麼時候停」（例如一直除以 2 直到變 0、輸入錯就重問）用 `while`。
3. 只印出一行 `3`。因為 `for (...);` 結尾的分號就是迴圈的「內容」（空的），迴圈空轉 3 次讓 i 變成 3；下面的 `{ }` 跟迴圈無關，只執行一次。實測連 `-Wall -Wextra` 都**沒有警告**，所以特別危險。
