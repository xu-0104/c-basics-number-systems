# 第 2 課：第一支 C 程式、變數、型別、printf、sizeof

## 1. 程式的骨架

```c
#include <stdio.h>      // ① 引入「標準輸入輸出」工具箱，printf 就在裡面

int main(void)          // ② 程式從 main 開始執行；int 代表它最後會回傳一個整數
{                       // ③ 大括號 = 一個區塊的開始
    printf("Hello, C!\n");   // ④ 印出文字；\n = 換行；每句結尾一定要分號 ;
    return 0;           // ⑤ 回傳 0 給作業系統 = 「程式正常結束」
}                       // ⑥ 區塊結束
```

比喻：`main` 是一份食譜，`{ }` 框住所有步驟，每一步用 `;` 結尾，`#include` 是「先去倉庫把工具拿來」。

註解寫法：`// 單行註解` 或 `/* 多行註解 */`，編譯器會忽略它們。

## 2. 從 .c 到 .exe：編譯在做什麼？

```
hello.c ──(gcc 編譯)──▶ hello.exe ──(執行)──▶ 螢幕輸出
 人看得懂的文字            電腦看得懂的 0 和 1
```

面試可能會問「編譯的四個階段」，先記名字就好：
**前處理**（處理 `#include`、`#define`）→ **編譯**（C 變組合語言）→ **組譯**（變機器碼 .o）→ **連結**（把你的程式和 printf 等函式庫接起來變 .exe）

在 VS Code：`Ctrl+Shift+B` 編譯；`Ctrl+Shift+P` → `Run Task` → 「C: 編譯並執行目前檔案」。

## 3. 變數：有名字、有型別的「盒子」

```c
int age = 25;          // 宣告一個叫 age 的整數盒子，放進 25
age = 26;              // 之後可以換掉裡面的值
```

**型別決定盒子多大（幾個 byte）**，也就決定能放多大的數字——這就是第 1 課學的：

| 型別 | 用途 | 大小（你的電腦實測） | 範圍 |
|---|---|---|---|
| `char` | 一個字元 / 很小的整數 | 1 byte = 8 bit | `signed`: −128～127；`unsigned`: 0～255 |
| `short` | 小整數 | 2 bytes | `unsigned`: 0～65535 (`0xFFFF`) |
| `int` | 一般整數（最常用） | 4 bytes | 約 ±21 億 |
| `long` | 整數 | **4 bytes（Windows）／ 8 bytes（64 位元 Linux）** | 面試考點：大小依平台而定！ |
| `long long` | 大整數 | 8 bytes | 約 ±9.2×10¹⁸ |
| `float` | 小數（精度低） | 4 bytes | 約 7 位有效數字 |
| `double` | 小數（精度高，常用） | 8 bytes | 約 15 位有效數字 |

- 前面加 `unsigned` = 「不存負數」，同樣的 bit 數全拿來存正數，所以最大值變兩倍左右。
- C 標準只規定「最小要多大」，**實際大小由編譯器和平台決定**——所以要用 `sizeof` 確認，不要背死。

### 字元其實就是數字

```c
char letter = 'A';     // 單引號 = 一個字元
printf("%c %d %X\n", letter, letter, letter);   // 輸出：A 65 41
```

電腦裡沒有「字母」，只有數字。`'A'` 存的是 65（`0x41`），這張對照表叫 **ASCII**。

## 4. printf：格式化輸出

`printf("格式字串", 值1, 值2, ...)`，格式字串裡的 `%?` 會依序被後面的值取代。

| 寫法 | 意思 | `n = 200` 的輸出 |
|---|---|---|
| `%d` | 十進位整數 | `200` |
| `%u` | 無號（unsigned）十進位 | `200` |
| `%x` / `%X` | 十六進位（小寫 / 大寫） | `c8` / `C8` |
| `%#x` | 十六進位，自動加 `0x` | `0xc8`（注意：`%#X` 會變成 `0XC8`，想要 `0xC8` 就寫 `0x%X`） |
| `%08X` | 補 0 湊滿 8 位 | `000000C8` |
| `%o` | 八進位 | `310` |
| `%c` | 字元 | — |
| `%f` / `%.2f` | 小數 / 小數點後 2 位 | — |
| `%zu` | `sizeof` 的結果 | — |

> printf **沒有**印二進位的格式！要自己寫迴圈——這就是第 6 課 `baseconv` 要做的事。

## 5. sizeof：問「這個盒子幾個 byte」

```c
printf("%zu\n", sizeof(int));    // 4
int x;
printf("%zu\n", sizeof(x));      // 也可以問變數：4
```

`sizeof` 是**運算子**不是函式（面試考點），在編譯時就算好了。

## 6. scanf：從鍵盤讀輸入

```c
int n;
printf("請輸入一個整數：");
scanf("%d", &n);       // 注意 n 前面的 &
```

`&n` 是「n 這個盒子的**地址**」。scanf 要知道盒子在哪裡，才能把讀到的值放進去。（為什麼要地址 → 第 2 個聊天室「指標」會講透。現在先記：**scanf 的變數前面要加 `&`**。）

## 7. 兩個新手一定會踩的坑

**坑 1：整數除法會丟掉小數**

```c
printf("%d\n", 7 / 2);       // 3，不是 3.5！
printf("%f\n", 7 / 2.0);     // 3.500000 ← 有一邊是小數，結果才是小數
```

**坑 2：溢位（overflow）—— 盒子裝不下會「繞回去」**

```c
unsigned char c = 255;   // 1111 1111，已經是最大值
c = c + 1;               // 1 0000 0000 → 第 9 個 bit 裝不下被丟掉
printf("%d\n", c);       // 0
```

像汽車里程表 999999 再走 1 公里變成 000000。這就是第 1 課「1 byte 最大 255」在程式裡的真實後果。

## 8. scanf 深入（以下行為都實際編譯測試過）

### 8-1. 輸入緩衝區：scanf 不是直接讀鍵盤

你打的字（包含最後按的 Enter = `'\n'`）會先排進一條「輸入緩衝區」，scanf 從前面拿走它看得懂的部分，**看不懂的會留在原地**。

```
你輸入：3 7⏎        緩衝區：[ '3' ' ' '7' '\n' ]
scanf("%d %d", &a, &b);  → 拿走 3 和 7，'\n' 還留著！
```

### 8-2. 常用格式

| 格式 | 讀什麼 | 例：輸入 → 結果 |
|---|---|---|
| `%d` | 十進位整數 | `42` → 42 |
| `%x` | 十六進位整數（變數要 `unsigned int`） | `ff` → 255 ← **baseconv 會用到！** |
| `%o` | 八進位整數 | `310` → 200 |
| `%f` / `%lf` | `float` / `double`（注意 double 是 `%lf`，printf 則用 `%f`） | `3.5` → 3.5 |
| `%c` | 一個字元（**包含空白和換行**） | |
| `%s` | 一個字（遇到空白就停，陣列前**不加** `&`） | `Hello World` → `Hello` |

- `%d %d` 中間的空白代表「跳過任意數量的空白/換行」，所以 `3 7`、`3⏎7` 都讀得到。
- `%d`、`%x`、`%s` 本來就會自動跳過前面的空白和換行；**只有 `%c` 不會**。

### 8-3. 回傳值：scanf 會告訴你「成功讀了幾個」

```c
int r = scanf("%d %d", &a, &b);
```

| 情況 | r |
|---|---|
| 兩個都讀到 | 2 |
| 輸入 `abc`（不是數字） | 0，而且 a 的值**不會被改** |
| 輸入結束（檔案結尾 / Ctrl+Z） | `EOF`（= −1） |

**正式程式一定要檢查回傳值**，不然使用者亂打時，程式會拿一個沒被設定的值繼續算。

### 8-4. 三大陷阱

**陷阱 1：`%c` 讀到上一行剩下的 Enter**

```c
scanf("%d", &n);     // 輸入 5⏎，'\n' 留在緩衝區
scanf("%c", &ch);    // 直接拿走 '\n'（ASCII 10），根本沒等你打字！
scanf(" %c", &ch);   // ✅ %c 前面加空白 = 先跳過空白和換行
```

**陷阱 2：輸入錯誤會卡住**

輸入 `abc` 時 `%d` 讀不懂，`abc` 會**一直留在緩衝區**，下一次 `scanf("%d")` 又讀到 `abc`、又失敗……放在迴圈裡就變成無窮迴圈。解法：把這一行剩下的字丟掉：

```c
int ch;
while ((ch = getchar()) != '\n' && ch != EOF) { }   // 一直讀到換行為止，全部丟掉
```

**陷阱 3：`%s` 不限長度會寫爆陣列**

```c
char word[8];
scanf("%s", word);    // ❌ 輸入超過 7 個字就寫到陣列外面（緩衝區溢位，資安漏洞）
scanf("%7s", word);   // ✅ 最多讀 7 個字（留 1 格給字串結尾的 '\0'）
```

讀 `HelloWorld` 會得到 `HelloWo`，剩下的 `rld` **還留在緩衝區**（又是 8-1）。

### 8-5. 忘記 `&` 會怎樣？

```c
scanf("%d", n);   // ❌
```

gcc 加 `-Wall` 會警告：`format '%d' expects argument of type 'int *', but argument 2 has type 'int'`。
執行時 scanf 會把 n 裡面的**垃圾值當成地址**去寫，通常程式直接當掉。→ **永遠用 `-Wall` 編譯，警告當錯誤看。**

### 8-6. 安全讀一個整數的標準寫法

```c
int n;
printf("請輸入一個整數：");
if (scanf("%d", &n) != 1) {
    printf("輸入錯誤，不是整數！\n");
    return 1;              // 回傳非 0 = 程式異常結束
}
printf("你輸入的是 %d\n", n);
```
