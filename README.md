# C Basics & Number Systems

從零開始學 C 語言基礎，以及二進位 / 十進位 / 十六進位換算的學習紀錄與作品。
最終作品：一個用 C 寫的命令列進位轉換工具 `baseconv`。

| 2 | 第一支 C 程式、變數、型別、`printf`、`sizeof` | [notes/02-first-c-program.md](notes/02-first-c-program.md)、`exercises/02_*.c` | ⬜ |

| 4 | 函式：費氏數列（迴圈版 + 遞迴版） | `exercises/04_*.c` | ⬜ |

| 6 | **期末作品：`baseconv` 進位轉換工具** | `baseconv/` | ⬜ |
